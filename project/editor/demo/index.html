Runtime demo

The default Mascot Face, exported from the editor and driven by the standalone runtime — the same mascot.svg, rig.json and runtime.js that Export downloads, loaded here the way a web page loads them. Click the mascot to make it nod.

Use it on your site

<div id="mascot"></div>
<script type="module">
  import { load } from './runtime.js';
  const mascot = await load({ mount: '#mascot', svg: './mascot.svg', rig: './rig.json' });
  mascot.setState('happy');
  mascot.playMotion('head-nod');
  mascot.setParameter('lookX', 0.5);
</script>
  • mascot.svg — the artwork
  • rig.json — parameters, states, motions, behaviours and the 2.5D head turn
  • runtime.js — the standalone ES module (no eval, no dependencies)

Everything runs in this page. No account, backend or tracking; the runtime API is documented in docs/RUNTIME_API.md.
